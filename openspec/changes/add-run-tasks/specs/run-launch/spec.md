# Spec Delta

## Purpose

Запуск готового шаблону процесу для конкретного випадку: менеджер або адміністратор створює запуск, стає його менеджером і розподіляє задачі між виконавцями; запуск зберігає шаблон у тому вигляді, в якому він був на момент запуску.

## ADDED Requirements

### Requirement: Запуск шаблону створює запуск з усіма задачами
WHEN менеджер або адміністратор запускає шаблон для випадку, the system SHALL створити один запуск зі статусом «in progress», що містить усі задачі шаблону зі статусом «to do».

#### Scenario: AC-RUN-01 Запуск шаблону «Tenant move-in» менеджером
- **GIVEN** шаблон «Tenant move-in» з 2 секціями і 5 задачами, 3 з яких обов'язкові, і менеджер A
- **WHEN** менеджер A запускає цей шаблон для випадку «Apartment 12, move-in»
- **THEN** створено рівно один запуск зі статусом «in progress»
- **AND** запуск містить усі 5 задач зі статусом «to do»

### Requirement: Запуск не змінюється після зміни шаблону
WHILE запуск існує, the system SHALL зберігати в ньому задачі шаблону з їхніми початковими назвами, незалежно від подальших змін шаблону.

#### Scenario: AC-RUN-02 Зміна шаблону не змінює створений запуск
- **GIVEN** запуск, створений із шаблону «Tenant move-in» з 5 задачами, і менеджер запуску
- **WHEN** шаблон змінено (додано шосту задачу й перейменовано першу задачу), після чого менеджер запуску відкриває запуск
- **THEN** запуск усе ще містить рівно 5 задач з їхніми початковими назвами

### Requirement: Назва випадку не може бути порожньою
IF назва випадку порожня або складається лише з пробілів, THEN the system SHALL відхилити запуск без створення запуску й показати повідомлення «Enter a case name».

#### Scenario: AC-RUN-03 Порожня назва випадку або лише пробіли
- **GIVEN** менеджер A і шаблон з 5 задачами
- **WHEN** менеджер A запускає шаблон з порожньою назвою випадку або з назвою, що складається лише з пробілів
- **THEN** запуск не створено
- **AND** менеджер A бачить повідомлення «Enter a case name»

### Requirement: Назва випадку обмежена 100 символами
IF назва випадку довша за 100 символів, THEN the system SHALL відхилити запуск без створення запуску й показати повідомлення «Case name must be at most 100 characters».

#### Scenario: AC-RUN-07 Назва випадку із 101 символу
- **GIVEN** менеджер A і шаблон з 5 задачами
- **WHEN** менеджер A запускає шаблон з назвою випадку у 101 символ
- **THEN** запуск не створено
- **AND** менеджер A бачить повідомлення «Case name must be at most 100 characters»

### Requirement: Користувач, що запустив шаблон, стає менеджером запуску
WHEN менеджер або адміністратор запускає шаблон, the system SHALL призначити цього користувача менеджером створеного запуску.

#### Scenario: AC-RUN-05 Адміністратор запускає шаблон
- **GIVEN** адміністратор і шаблон «Tenant move-in» з 5 задачами
- **WHEN** адміністратор запускає цей шаблон для випадку «Apartment 14, move-in»
- **THEN** створено рівно один запуск
- **AND** менеджер запуску — цей адміністратор

#### Scenario: AC-RUN-06 Менеджер запускає шаблон
- **GIVEN** шаблон «Tenant move-in» і менеджер A
- **WHEN** менеджер A запускає його для випадку «Apartment 12, move-in»
- **THEN** менеджер A — менеджер створеного запуску

### Requirement: Виконавці окремих задач призначаються під час запуску
WHEN менеджер запуску призначає іншого користувача виконавцем окремих задач під час запуску, the system SHALL призначити його виконавцем саме цих задач, а виконавцем решти задач — менеджера запуску.

#### Scenario: AC-RUN-04 Менеджер A призначає менеджера B виконавцем двох задач
- **GIVEN** шаблон з 5 задачами та менеджери A і B
- **WHEN** менеджер A запускає шаблон і призначає менеджера B виконавцем двох задач
- **THEN** ці 2 задачі мають виконавцем менеджера B
- **AND** решта 3 задач мають виконавцем менеджера A

### Requirement: Без призначення виконавець усіх задач — менеджер запуску
WHEN менеджер запуску запускає шаблон без призначення виконавців, the system SHALL призначити його виконавцем усіх задач запуску.

#### Scenario: AC-RUN-08 Менеджер запускає шаблон без виконавців
- **GIVEN** шаблон з 5 задачами і менеджер A
- **WHEN** менеджер A запускає шаблон, не призначаючи жодного виконавця
- **THEN** менеджер A — виконавець усіх 5 задач

#### Scenario: AC-RUN-09 Адміністратор запускає шаблон без виконавців
- **GIVEN** шаблон з 5 задачами і адміністратор
- **WHEN** адміністратор запускає шаблон, не призначаючи жодного виконавця
- **THEN** адміністратор — виконавець усіх 5 задач
